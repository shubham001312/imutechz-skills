# Examples

Past outputs of this skill: a quality bar to compare against after the direction is set from live `fishvideo trends` research. They are not templates, the skill does not need them to run, and nothing in them is a current trend. Do not copy their structure, words, images or look. Each folder has the brief, storyboard, custom scene code, post text, credits, QA result, a frame sheet, a thumbnail or cover, a small 720p sample video and a README with the recipe, licences and gate result. Photo and screenshot files are not committed; the README of each example says which ones appear in its video.

| Example | Format | Recipe | Notes |
|---|---|---|---|
| `genai-roadmap-long/` | 16:9, 44 s excerpt of a 9:15 film | roadmap-explainer | silent-film memes, site tiles, designed thumbnail |
| `onoda-story-series/` | two 9:16 Shorts (25-27 s) | story-short | archive photos; three images have an uncertain licence basis (see its README) |
| `gta6-short/` | 9:16, 28.5 s | bold-short | typography only, no game art |

Never reuse their narration or images, or repeat their scene sequence (the gate blocks all three). Each uses custom scenes (`scenes/custom.js`); a new video may use built-in scenes or its own. All three predate some gates, so the full `gate` on a copy fails without the uncommitted images (or, for `gta6-short`, the imagery gate); each README says why.

Gate note: a verbatim copy of an example now also fails `gate` by design (identical scene sequence, no live trend research). Gate results in each README were taken at the time of writing, on a copy with the trend and sameness checks set aside; the failures listed there (missing uncommitted images, the typographic Short's imagery rule) are the ones that matter.
